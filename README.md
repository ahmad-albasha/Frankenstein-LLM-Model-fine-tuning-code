# 📚 Fine-Tuning Mistral-7B on *Frankenstein* 🧪⚡

> **Goal:** Fine-tuning [Mistral-7B-v0.1](https://huggingface.co/mistralai/Mistral-7B-v0.1) on the text of *Frankenstein* to generate coherent and contextually rich answers inspired by the novel.

---

## 🚀 Project Overview
This project demonstrates how to fine-tune the powerful **Mistral-7B** language model using the classic novel *Frankenstein* as a training dataset.  
The resulting model is capable of generating responses and insights in the style and context of the book.
